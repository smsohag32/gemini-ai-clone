# **Gemini Clone AI Project**

This project is a clone of the Gemini AI system, leveraging the Gemini API for intelligent interactions. It is built with modern web technologies, including **JavaScript**, **React.js**, **Tailwind CSS**, and the **Shadcn component library** for UI components.

## **Features**

-  **AI-Powered Interactions**: Uses Gemini API for robust AI capabilities.
-  **Responsive Design**: Styled with Tailwind CSS for a mobile-first responsive UI.
-  **Reusable Components**: Built with Shadcn UI components for consistent and modular design.
-  **Modern Frontend Stack**: Built with React.js for seamless user experiences.

---

## **Technologies Used**

### **Frontend**

-  **React.js**: For building a dynamic and interactive UI.
-  **Tailwind CSS**: For rapid styling and responsive designs.
-  **Shadcn Component Library**: For pre-built, customizable components.

### **Backend/AI Integration**

-  **Gemini API**: Provides AI functionality and intelligent response mechanisms.
